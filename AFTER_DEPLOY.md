1. Откройте [Render Dashboard](https://dashboard.render.com)
2. Выберите ваш сервис `telegram-predictions-bot`
3. Перейдите во вкладку **"Logs"**
4. Убедитесь, что видите:

- Проверьте, что `BOT_TOKEN` правильно прописан в Environment

## 🔧 Настройка и оптимизация

### Изменить интервал проверки

Если хотите, чтобы бот проверял чаще/реже:

1. В Render → вкладка **Environment**
2. Найдите `CHECK_INTERVAL`
3. Измените значение:
   - `180` = каждые 3 минуты
   - `300` = каждые 5 минут (по умолчанию)
   - `600` = каждые 10 минут
4. Сохраните → бот автоматически перезапустится

### Добавить новые турниры

1. Откройте файл `config.py` в вашем GitHub репозитории
2. Найдите словарь `TOURNAMENTS`
3. Добавьте новые турниры:
   ```python
   TOURNAMENTS = {
       'football': [
           'РПЛ',
           'АПЛ',
           'Новый турнир',  # Добавьте сюда
       ],
   }
   ```
4. Сохраните → Render автоматически задеплоит изменения

### Добавить новые виды спорта

1. В `config.py` добавьте в `SPORTS`:
   ```python
   SPORTS = {
       'volleyball': '🏐 Волейбол',  # Новый вид
   }
   ```
2. И в `TOURNAMENTS`:
   ```python
   TOURNAMENTS = {
       'volleyball': ['Суперлига России'],
   }
   ```

## 🐛 Решение проблем

### Бот не отвечает в Telegram

**Проверьте:**
1. Статус сервиса в Render (должен быть "Live")
2. Логи - есть ли сообщение "✅ Бот запущен"?
3. Переменные окружения - правильный ли `BOT_TOKEN`?

**Решение:**
- Перезапустите сервис: **Manual Deploy** → **Deploy latest commit**
- Проверьте токен в @BotFather

### Прогнозы не приходят

**Проверьте:**
1. Выбраны ли виды спорта? (отправьте `/settings`)
2. Работает ли планировщик? (в логах должно быть "🔍 Проверяю")
3. Есть ли новые прогнозы на Sports.ru?

**Решение:**
- Подождите 5 минут после выбора видов спорта
- Проверьте https://www.sports.ru/predictions/ - есть ли там новые статьи

### Сервис постоянно засыпает

**Причина:** Бесплатный план Render засыпает после 15 минут неактивности.

**Решение:**
- Настройте UptimeRobot (см. пункт 4 выше)
- Или upgrade на Starter план ($7/мес) для 24/7 работы

### Ошибка "Too Many Requests"

**Причина:** Превышен лимит Telegram (30 сообщений/секунду).

**Решение:**
В `scheduler.py` увеличьте задержку:
```python
await asyncio.sleep(0.1)  # Было 0.05
```
