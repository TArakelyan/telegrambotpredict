# FAQ - Часто задаваемые вопросы

## Общие вопросы

### Как работает бот?

Бот автоматически проверяет раздел прогнозов на Sports.ru каждые 5 минут, парсит новые прогнозы и отправляет их пользователям согласно их подпискам.

### Бесплатно ли это?

Да! Бот полностью бесплатный. Render.com предоставляет бесплатный план с ограничениями:
- 750 часов работы в месяц (достаточно для круглосуточной работы одного сервиса)
- Сервис засыпает после 15 минут неактивности

### Какие виды спорта поддерживаются?

По умолчанию:
- ⚽️ Футбол
- 🏒 Хоккей
- 🏀 Баскетбол
- 🎾 Теннис

Можно добавить другие в файле `config.py`.

## Настройка и использование

### Как изменить интервал проверки прогнозов?

В файле `.env` измените параметр `CHECK_INTERVAL`:
```
CHECK_INTERVAL=180  # 3 минуты
CHECK_INTERVAL=300  # 5 минут (по умолчанию)
CHECK_INTERVAL=600  # 10 минут
```

### Как добавить новые турниры?

Откройте `config.py` и добавьте турниры в словарь `TOURNAMENTS`:

```python
TOURNAMENTS = {
    'football': [
        'РПЛ',
        'АПЛ',
        'Ла Лига',
        'Серия А',
        'Ваш новый турнир',  # Добавьте сюда
    ],
    # ...
}
```

После изменения нужно передеплоить бота на Render.

### Как добавить новый вид спорта?

В `config.py` добавьте в словарь `SPORTS`:

```python
SPORTS = {
    'football': '⚽️ Футбол',
    'hockey': '🏒 Хоккей',
    'volleyball': '🏐 Волейбол',  # Новый вид спорта
}
```

И добавьте турниры для него:

```python
TOURNAMENTS = {
    'volleyball': [
        'Суперлига России',
        'Лига чемпионов',
    ],
}
```

### Можно ли изменить формат сообщений?

Да! Откройте `scheduler.py` и измените метод `_format_prediction_message()`.

## Проблемы и решения

### Бот не отвечает на команды

**Причины:**
1. Сервис не запущен на Render
2. Неправильный токен бота
3. Webhook настроен неправильно

**Решение:**
1. Проверьте статус на Render (должен быть "Live")
2. Проверьте логи на наличие ошибок
3. Убедитесь, что `WEBHOOK_URL` настроен правильно в переменных окружения

### Бот не присылает прогнозы

**Причины:**
1. Не выбраны виды спорта
2. Планировщик не работает
3. Нет новых прогнозов на Sports.ru

**Решение:**
1. Отправьте `/start` и выберите виды спорта
2. Проверьте логи - должно быть "🔍 Проверяю новые прогнозы..."
3. Подождите появления новых прогнозов на сайте

### Сервис постоянно засыпает

**Причина:**
На бесплатном плане Render сервис засыпает после 15 минут неактивности.

**Решение:**

**Вариант 1: Upgrade на платный план**
- $7/месяц
- Сервис работает 24/7

**Вариант 2: Uptime мониторинг (бесплатно)**
1. Зарегистрируйтесь на [UptimeRobot](https://uptimerobot.com)
2. Добавьте новый монитор:
   - Type: HTTP(s)
   - URL: `https://ваш-сервис.onrender.com`
   - Monitoring Interval: 5 минут
3. UptimeRobot будет пинговать ваш сервис и не давать ему заснуть

### Ошибка "Too Many Requests" в Telegram

**Причина:**
Превышен лимит отправки сообщений Telegram (30 сообщений в секунду на бота).

**Решение:**
В `scheduler.py` уже добавлена задержка между отправками:
```python
await asyncio.sleep(0.05)  # 50 мс между сообщениями
```

Если нужно, увеличьте задержку до 0.1 секунды.

### Прогнозы дублируются

**Причина:**
База данных не сохраняет отправленные прогнозы.

**Решение:**
1. Проверьте, что файл `predictions_bot.db` создается
2. Проверьте права на запись в папку проекта

### Парсер не находит прогнозы

**Причина:**
Структура сайта Sports.ru изменилась.

**Решение:**
1. Запустите `test_parser.py` для проверки
2. Обновите селекторы в `parser.py`
3. Откройте issue на GitHub с описанием проблемы

## База данных

### Как посмотреть статистику?

Если используете SQLite локально:

```bash
# Подключиться к базе
sqlite3 predictions_bot.db

# Количество пользователей
SELECT COUNT(*) FROM users WHERE is_active = 1;

# Количество отправленных прогнозов
SELECT COUNT(*) FROM sent_predictions;

# Популярные виды спорта
SELECT sport, COUNT(*) as count 
FROM user_sports 
GROUP BY sport 
ORDER BY count DESC;

# Выход
.quit
```

### Как сбросить базу данных?

**Локально:**
```bash
rm predictions_bot.db
python bot.py  # База создастся заново
```

**На Render:**
1. Зайдите в Shell на Render
2. Выполните: `rm predictions_bot.db`
3. Перезапустите сервис

### Можно ли использовать PostgreSQL?

Да! Render предоставляет бесплатную PostgreSQL:

1. Создайте новую PostgreSQL базу на Render
2. Скопируйте Internal Database URL
3. Добавьте в переменные окружения:
   ```
   DATABASE_URL=postgresql://user:password@host:5432/dbname
   ```
4. Измените `database.py` для работы с PostgreSQL (используйте библиотеку `psycopg2`)

## Разработка

### Как добавить новую команду?

1. Добавьте обработчик в `handlers.py`:
```python
async def my_command(update: Update, context: ContextTypes.DEFAULT_TYPE):
    await update.message.reply_text("Ответ на команду")
```

2. Зарегистрируйте в `bot.py`:
```python
application.add_handler(CommandHandler("mycommand", handlers.my_command))
```

Откройте `keyboards.py` и измените нужную функцию.

## Безопасность

### Безопасно ли хранить токен в .env?

**Локально:** Да, если `.env` добавлен в `.gitignore`

**На GitHub:** Нет! Никогда не загружайте `.env` в публичный репозиторий

**На Render:** Да, переменные окружения хранятся безопасно

### Как защитить бота от спама?

Добавьте rate limiting в `handlers.py`:

```python
from datetime import datetime, timedelta

# Словарь для хранения времени последнего запроса
last_request = {}

async def start_command(update: Update, context: ContextTypes.DEFAULT_TYPE):
    user_id = update.effective_user.id
    now = datetime.now()
    
    # Проверка: не более 1 запроса в 5 секунд
    if user_id in last_request:
        if now - last_request[user_id] < timedelta(seconds=5):
            await update.message.reply_text("Слишком частые запросы!")
            return
    
    last_request[user_id] = now
    # ... остальной код
```

## Мониторинг

### Как получать уведомления об ошибках?

**Вариант 1: Email от Render**
В настройках Render включите email уведомления о сбоях.

**Вариант 2: Sentry (бесплатно до 5K событий/мес)**
1. Зарегистрируйтесь на [Sentry.io](https://sentry.io)
2. Установите: `pip install sentry-sdk`
3. Добавьте в `bot.py`:
```python
import sentry_sdk
sentry_sdk.init("your_dsn_here")
```

### Как посмотреть метрики?

В Render перейдите во вкладку **"Metrics"**:
- CPU usage
- Memory usage
- Response time
- Request count

## Юридические вопросы

### Можно ли использовать контент Sports.ru?

Вы парсите публичный контент для личных уведомлений. Это находится в серой зоне.

**Рекомендации:**
- Не монетизируйте бота напрямую
- Используйте партнерские ссылки Sports.ru
- Указывайте источник (Sports.ru)
- При запросе Sports.ru - остановите бота

### Можно ли продавать доступ к боту?

Технически можно, но:
1. Нужно согласие Sports.ru на использование их контента
2. Рассмотрите создание официального API или партнерства
