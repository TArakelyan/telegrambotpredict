# Быстрый старт

## Вариант 1: Загрузка на GitHub вручную (если нет git)

### Шаг 1: Создайте репозиторий на GitHub

1. Откройте [GitHub](https://github.com) и войдите в свой аккаунт
2. Нажмите на **"+"** в правом верхнем углу → **"New repository"**
3. Введите название: `telegram-predictions-bot`
4. Выберите **"Public"** или **"Private"**
5. **НЕ** ставьте галочки на "Add a README file", "Add .gitignore" или "Choose a license"
6. Нажмите **"Create repository"**

### Шаг 2: Загрузите файлы

1. На странице нового репозитория нажмите **"uploading an existing file"**
2. Перетащите ВСЕ файлы из папки `telegram-predictions-bot` (кроме `.env` и `predictions_bot.db` если он есть)
3. Напишите сообщение коммита: "Initial commit"
4. Нажмите **"Commit changes"**

### Шаг 3: Переходите к деплою

Теперь следуйте инструкциям из файла `DEPLOY.md` начиная с раздела "Деплой на Render.com"

---

## Вариант 2: Локальное тестирование (перед деплоем)

### Шаг 1: Установите Python

Убедитесь, что установлен Python 3.10 или выше:
```bash
python --version
```

### Шаг 2: Установите зависимости

```bash
cd telegram-predictions-bot
pip install -r requirements.txt
```

### Шаг 3: Настройте файл .env

Файл `.env` уже создан с правильным токеном. Убедитесь, что `WEBHOOK_URL` пустой для локального запуска.

### Шаг 4: Запустите бота

```bash
python bot.py
```

Вы должны увидеть:
```
✅ Планировщик запущен. Интервал проверки: 300 сек.
✅ Бот запущен и готов к работе!
```

### Шаг 5: Протестируйте

1. Откройте Telegram
2. Найдите вашего бота
3. Отправьте `/start`
4. Выберите виды спорта

### Остановка бота

Нажмите `Ctrl+C` в терминале для остановки.

## Полезные команды бота

- `/settings` - Изменить настройки подписок
- `/stop` - Отключить уведомления
- `/help` - Справка по командам

---

## Как это работает

1. **Бот запускается** и инициализирует базу данных
2. **Планировщик** каждые 5 минут (настраивается) проверяет Sports.ru
3. **Парсер** извлекает новые прогнозы с страницы `/predictions/`
4. **Для каждого прогноза**:
   - Определяется вид спорта и турнир
   - Находятся подписанные пользователи
   - Отправляется сообщение с кратким описанием и кнопкой
5. **База данных** хранит:
   - Пользователей и их подписки
   - Отправленные прогнозы (чтобы не дублировать)

## Часто задаваемые вопросы

### Как изменить интервал проверки прогнозов?

В файле `.env` измените `CHECK_INTERVAL`:
- `60` = каждую минуту
- `300` = каждые 5 минут (по умолчанию)
- `600` = каждые 10 минут

### Можно ли добавить другие виды спорта?

Да! В файле `config.py` отредактируйте словарь `SPORTS` и `TOURNAMENTS`.

### Как посмотреть, сколько пользователей у бота?

Используйте SQLite клиент:
```bash
sqlite3 predictions_bot.db
SELECT COUNT(*) FROM users WHERE is_active = 1;
```

### Бот не присылает прогнозы

Проверьте:
1. Выбраны ли виды спорта (отправьте `/settings`)
2. Запущен ли планировщик (смотрите логи)
3. Есть ли новые прогнозы на Sports.ru
