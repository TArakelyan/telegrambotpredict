## 📖 Описание

Автоматический Telegram-бот для рассылки прогнозов со Sports.ru с возможностью персонализированной подписки по видам спорта и турнирам.

### Основные возможности

✅ **Автоматический парсинг** - бот самостоятельно отслеживает новые прогнозы на Sports.ru  
✅ **Персонализация** - пользователи выбирают интересующие виды спорта и турниры  
✅ **Умная фильтрация** - прогнозы отправляются только заинтересованным пользователям  
✅ **Отсутствие дубликатов** - каждый прогноз отправляется один раз  
✅ **Партнерские ссылки** - интеграция с букмекерами через Sports.ru  
✅ **Масштабируемость** - поддержка неограниченного количества пользователей

## 💾 База данных

### Схема БД (SQLite)

```sql
-- Пользователи
CREATE TABLE users (
    user_id INTEGER PRIMARY KEY,
    username TEXT,
    first_name TEXT,
    last_name TEXT,
    is_active INTEGER DEFAULT 1,
    created_at TIMESTAMP,
    updated_at TIMESTAMP
);

-- Подписки на виды спорта
CREATE TABLE user_sports (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER,
    sport TEXT,
    UNIQUE(user_id, sport)
);

-- Подписки на турниры
CREATE TABLE user_tournaments (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER,
    sport TEXT,
    tournament TEXT,
    UNIQUE(user_id, sport, tournament)
);

-- Отправленные прогнозы
CREATE TABLE sent_predictions (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    prediction_url TEXT UNIQUE,
    title TEXT,
    sport TEXT,
    tournament TEXT,
    sent_at TIMESTAMP
);
```

## 🔄 Workflow

### Жизненный цикл прогноза

1. **Парсинг** (каждые 5 минут)
   - Бот проверяет https://www.sports.ru/predictions/
   - Находит новые статьи с прогнозами

2. **Извлечение данных**
   - Заголовок матча
   - Дата и время
   - Турнир и вид спорта
   - Краткое описание (2 абзаца)
   - Партнерская ссылка

3. **Фильтрация**
   - Определяется вид спорта и турнир
   - Из БД извлекаются подходящие пользователи

4. **Отправка**
   - Каждому пользователю отправляется сообщение
   - С кнопкой для перехода на букмекера

5. **Сохранение**
   - URL прогноза сохраняется в БД
   - Предотвращается повторная отправка

### Алгоритм фильтрации

```python
# Пользователь получает прогноз, если:
1. Пользователь активен (is_active = 1)
2. Подписан на вид спорта прогноза
3. И либо:
   a) Не выбрал конкретные турниры (получает все)
   б) Подписан на турнир этого прогноза
```

## 🚀 Производительность

### Оптимизации

- **Асинхронность** - все IO операции асинхронные
- **Кэширование** - парсим прогноз только один раз
- **Batch запросы** - группировка пользователей по подпискам
- **Rate limiting** - задержки между отправками (Telegram API limits)

### Лимиты

**Telegram API:**
- 30 сообщений/секунду на бота
- Решение: задержка 50ms между сообщениями

**Render Free Plan:**
- 512 MB RAM
- 0.1 CPU
- Засыпает после 15 минут неактивности
