# Инструкция по деплою на Render.com

## Подготовка

### 1. Создание репозитория на GitHub

1. Зайдите на [GitHub](https://github.com)
2. Создайте новый репозиторий (можно назвать `telegram-predictions-bot`)
3. Не добавляйте README, .gitignore или лицензию (они уже есть в проекте)

### 2. Загрузка кода в GitHub

Откройте терминал в папке проекта и выполните:

```bash
# Инициализируйте git (если еще не сделано)
git init

# Добавьте все файлы
git add .

# Создайте коммит
git commit -m "Initial commit: Telegram predictions bot"

# Добавьте удаленный репозиторий (замените YOUR_USERNAME на ваш username)
git remote add origin https://github.com/YOUR_USERNAME/telegram-predictions-bot.git

# Отправьте код
git branch -M main
git push -u origin main
```

## Деплой на Render.com

### 1. Регистрация на Render

1. Перейдите на [Render.com](https://render.com)
2. Зарегистрируйтесь или войдите через GitHub

### 2. Создание Web Service

1. На главной странице Render нажмите **"New +"** → **"Web Service"**
2. Подключите ваш GitHub репозиторий:
   - Нажмите **"Connect account"** для GitHub
   - Выберите репозиторий `telegram-predictions-bot`
   - Нажмите **"Connect"**

### 3. Настройка сервиса

Заполните форму создания сервиса:

- **Name**: `telegram-predictions-bot` (или любое другое имя)
- **Region**: выберите ближайший регион (например, Frankfurt)
- **Branch**: `main`
- **Root Directory**: оставьте пустым
- **Runtime**: `Python 3`
- **Build Command**: `pip install -r requirements.txt`
- **Start Command**: `python bot.py`

### 4. Выбор плана

- Выберите **"Free"** план (бесплатный)
- Нажмите **"Create Web Service"**

### 5. Настройка переменных окружения

После создания сервиса:

1. Перейдите во вкладку **"Environment"**
2. Добавьте переменные окружения:

```
BOT_TOKEN = 8399906862:AAGztEPgwD6QgI2AOnKo0yF8_I8jYiOfpyY
WEBHOOK_URL = https://ваш-сервис.onrender.com
CHECK_INTERVAL = 300
```

⚠️ **Важно**: Замените `https://ваш-сервис.onrender.com` на реальный URL вашего сервиса (его можно найти в верхней части страницы сервиса)

3. Нажмите **"Save Changes"**

### 6. Деплой

Render автоматически начнет деплой после сохранения переменных окружения. Процесс займет 2-3 минуты.

Следите за логами во вкладке **"Logs"** - там вы увидите:
```
✅ Планировщик запущен. Интервал проверки: 300 сек.
✅ Бот запущен и готов к работе!
```

## Проверка работы

### 1. Тестирование бота

1. Откройте Telegram
2. Найдите вашего бота (имя, которое вы указали в @BotFather)
3. Отправьте команду `/start`
4. Бот должен ответить и предложить выбрать виды спорта

### 2. Мониторинг логов

Во вкладке **"Logs"** на Render вы будете видеть:
- 🔍 Когда бот проверяет новые прогнозы
- ✨ Когда находит новые прогнозы
- 📤 Когда отправляет их пользователям

## Возможные проблемы и решения

### Бот не отвечает

1. Проверьте, что сервис запущен (статус "Live" в Render)
2. Проверьте логи на наличие ошибок
3. Убедитесь, что `BOT_TOKEN` правильный

### Бот не присылает прогнозы

1. Проверьте, что вы выбрали виды спорта через `/start`
2. Подождите 5 минут (интервал проверки)
3. Проверьте логи - там должно быть "🔍 Проверяю новые прогнозы..."

### Сервис засыпает (Free план)

На бесплатном плане Render сервис засыпает после 15 минут неактивности. Решения:

1. **Upgrade на платный план** ($7/мес) - сервис будет работать 24/7
2. **Использовать uptime мониторинг** - сервисы типа UptimeRobot будут пинговать ваш сервис каждые 5 минут

## Обновление бота

Когда вы внесете изменения в код:

```bash
git add .
git commit -m "Описание изменений"
git push
```

Render автоматически задеплоит новую версию.

## Полезные команды

### Посмотреть логи
В Render: вкладка **"Logs"**

### Перезапустить сервис
В Render: кнопка **"Manual Deploy"** → **"Clear build cache & deploy"**

### Откатиться на предыдущую версию
В Render: вкладка **"Events"** → выберите деплой → **"Redeploy"**
