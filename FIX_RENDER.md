# 🔧 СРОЧНОЕ ИСПРАВЛЕНИЕ - Бот не работает на Render

## Проблема
Бот не запускается на Render (нет логов, не отвечает в Telegram).

## ✅ Быстрое решение (3 минуты)

### Шаг 1: Обновите код на GitHub

Я исправил файл `bot.py` - теперь бот всегда использует polling режим (надежнее для Render Free).

**Загрузите обновленный `bot.py` на GitHub:**

1. Откройте GitHub → ваш репозиторий `telegram-predictions-bot`
2. Найдите файл `bot.py`
3. Нажмите на карандаш (Edit this file)
4. Замените содержимое на обновленное из локальной папки
5. Commit changes: "Fix: switch to polling mode for Render"

**Или проще:** загрузите новый `bot.py` через Upload files

---

### Шаг 2: Удалите WEBHOOK_URL в Render

1. Откройте Render Dashboard
2. Ваш сервис → вкладка **Environment**
3. Найдите переменную `WEBHOOK_URL`
4. **Удалите её** (нажмите на крестик справа)
5. **Save Changes**

Render автоматически передеплоит бота с новыми настройками.

---

### Шаг 3: Проверьте через 2 минуты

1. Откройте вкладку **Logs**
2. Вы должны увидеть:
   ```
   🔄 Инициализация бота...
   🚀 Запуск в режиме polling...
   ✅ Планировщик запущен. Интервал проверки: 300 сек.
   ✅ Бот запущен и готов к работе!
   ```

3. Откройте Telegram → найдите бота → `/start`
4. Должен ответить! ✅

## 🎯 Альтернативный способ (если выше не помогло)

### Измените Start Command в Render

1. Render → Settings
2. **Start Command** измените на:
   ```
   python -u bot.py
   ```
3. **Manual Deploy** → Deploy latest commit

Флаг `-u` включает unbuffered вывод логов.

## 💡 Почему так?

**Проблема webhook на Render Free:**
- Render Free план имеет ограничения на входящие HTTP запросы
- Webhook требует стабильного URL и постоянной доступности
- Сервис засыпает после 15 мин неактивности = webhook не работает

**Почему polling лучше:**
- ✅ Бот сам подключается к Telegram
- ✅ Не требует входящих HTTP запросов  
- ✅ Работает даже после "пробуждения" сервиса
- ✅ Проще в настройке и отладке
